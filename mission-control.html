Every panel below is a free, public, no-signup feed. Each one is tagged with where the data came from right now: live straight from the source, cache from an earlier successful call, offline-snapshot bundled with the app, or unavailable.

🔑 NASA API key

NASA's DEMO_KEY works with no signup at 30 requests per hour. A free personal key from api.nasa.gov raises that to 1,000 per hour. It is stored only in this browser.

🔁 Optional CORS relay

JPL's Solar System Dynamics service is free and keyless, but it does not send CORS headers, so a browser cannot read its replies. Supplying any relay prefix — one that takes the target URL, encoded, on the end or in a {url} placeholder — unlocks the two JPL panels below. Everything else works without it.
