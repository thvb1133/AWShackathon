⚠️ Read this before anything else

This page prepares work. It does not earn money on its own, and nothing on it should be read as a promise that it will.

  • Software can do: run analyses on a schedule while you sleep, draft proposals, price a product, build the technical artefact, and put finished work in front of you to approve with one click.
  • Software cannot do: find customers, earn their trust, sign contracts, take payments you have not set up, or make somebody want the thing. Every business here needs a real person to sell it.
  • The one that pays first is almost never the cleverest. It is the one where you already know somebody with the problem.

Automating the work is real. Automating the customers is not.

🛰️ Idea #31, actually built: the Mission Optimiser

Of the fifty, this is the one implemented as working software rather than described. A satellite is asked for far more targets than it can fly. Choosing the subset that maximises mission value under a capacity limit is a 0/1 knapsack — NP-hard, and exactly the shape that maps onto a QUBO.

Four solvers run on the identical problem: greedy, simulated annealing, exact dynamic programming for ground truth, and a genuine QAOA on the state-vector simulator — cost-phase separator, RX mixer, angle search, then sampling. The verdict below is generated from the measured numbers, so if quantum loses, it says quantum lost.

🌙 What actually runs while you sleep

Honest mechanics, in one place. Scheduled crews run while a Beyond Orbit tab is open, including in the background. Close every tab and the schedule pauses; open one and anything overdue runs immediately, so you return to finished work. Each run files a draft into the approval inbox and nothing is sent anywhere until you approve it.
