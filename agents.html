What this is, honestly

This mesh is not a large language model and there is no server behind it. Every agent is a small deterministic specialist, and that is deliberate — it means each answer can be traced to its origin:

  • Calculating agents solve real equations: Kepler, Tsiolkovsky, Hohmann, SGP4, J2 precession, free-space path loss, radiative equilibrium.
  • Knowledge agents return codex records that cite who discovered the thing and when.
  • Feed agents call named public APIs — NASA, JPL, NOAA, CelesTrak, The Space Devs — and label whether the answer came live, from cache, or from the bundled snapshot.

Nothing here hallucinates a number, because nothing here is capable of inventing one. If an agent cannot answer, it says so.
